## 本机试用

入口仍为 https://127.0.0.1:18443 ，使用原试用实例账号。管理员随机密码的读取方式见 [TRIAL.md](TRIAL.md)。测试证书与数据库、附件卷沿用原实例。

UI 镜像单独标记为 `build-a-wiki-gateway:ui-refresh`，使用以下覆盖配置切换前端：

```bash
docker compose --env-file .data/compose-test.env -p wiki-acceptance \
  -f deploy/compose.yaml -f deploy/compose.ui-preview.yaml \
  up -d --no-deps --no-build --pull never gateway
```

回到原 `v0.1.0-rc1` 界面时，省略覆盖配置，仅重建 gateway 即可：

```bash
docker compose --env-file .data/compose-test.env -p wiki-acceptance \
  -f deploy/compose.yaml up -d --no-deps --no-build --pull never gateway
```

先前 `.data/releases/0.1.0-rc1` 离线包仍对应原候选版，未覆盖成新版 UI；当前 UI 改动、截图和验收记录另行提交 Git。本次视觉改版不替代 T59 的真实试用反馈或 T60 的正式发布交接。

首次 UI 改版验证于 2026-11-17 完成：原生浏览器 4 项通过（53.9 秒，HTTPS 专用项在原生环境按预期跳过），实际 HTTPS 入口专用项另行通过（1.1 秒）。当时 UI 镜像 ID 前缀 `afcbe35ccf96`，仅 gateway 容器更新；API、数据库及持久卷保留。构建仍有既存的 vendor 分包大于 500 kB 提示，不影响构建通过。
