# 高优先级交互动画

实现范围为会话中确定的六类高优先级场景。使用 CSS 过渡/关键帧及已有 Ant Design、React，不新增动画库或系统依赖。

| 场景 | 状态 | 行为 |
| --- | --- | --- |
| 目录展开、收起 | ✔ | 三角旋转与子目录高度/透明度过渡约 200ms。首次请求期间仅在展开按钮显示加载反馈，数据就绪后展开，不先闪空态；再次展开使用缓存并后台校验。 |
| 整个侧栏展开、收起 | ✔ | 桌面侧栏宽度与正文位置同步过渡约 220ms；侧栏内部保持原宽度，避免文字在缩窄过程中反复换行及滚动条闪现。手机使用高度收拢。 |
| 编辑与预览切换 | ✔ | 工具栏高度与透明度过渡约 200ms；标题淡入约 160ms并预留最小高度，正文框线平滑切换。保留同一个 Tiptap 实例，不重建正文或主动重置滚动位置。 |
| 提示消息 | ✔ | 正文保存成功、错误和个人草稿提示淡入，关闭时淡出并平滑收拢。保存成功仍在 5 秒后开始退场，也可点击右侧 × 关闭。 |
| 弹窗 | ✔ | 新建知识库、新建页面、链接编辑弹窗约 200ms 轻微位移/缩放入场，约 160ms 退场，遮罩同步淡变；创建弹窗等待退场后卸载。权限等确认浮层沿用 Ant Design 动画，并统一时长及减少动态效果设置。 |
| 新建节点反馈 | ✔ | 通过目录或知识库概览创建成功后，新节点约 200ms 淡入、短暂高亮约 1.8 秒；自动展开父级，必要时仅滚动侧栏定位新节点，不主动滚动正文。 |

## 连续操作和可访问性

- 收起后，正在退场的内容立即设置 `inert` 和 `aria-hidden`，不能被误点或继续获得键盘焦点；退场完成再卸载。
- 展开/收起可以反向接续。取消旧的动画调度与卸载定时器，避免快速操作后被旧回调错误隐藏。
- 不对后台自动刷新或正文输入反复播放进场动画；侧栏继续预留滚动条空间。
- 系统启用“减少动态效果”时，CSS 动画与过渡关闭，Ant Design 动画禁用；弹窗直接关闭、新节点使用静态短暂描边，定位改为即时滚动。
- 目录权限仍由服务器校验，缓存刷新失败或撤权不会保留原先的节点展示。

## 验证

`frontend/e2e/motion.spec.ts` 分别覆盖普通与减少动态效果模式：弹窗入场/退场及再次打开、新建库/页面高亮、侧栏快速反向开合及正文边缘同步、移动端侧栏开合、连续编辑/预览切换保持编辑器 DOM 与正文、提示关闭及遮罩退出。

已有目录延迟与滚动临界点测试继续运行，测量前等待目录过渡完成。最终原生浏览器 7 场景通过（约 1.2 分钟，HTTPS 专用项按预期跳过），8 项前端单元测试、TypeScript/格式检查、生产构建通过。构建仍有此前的 vendor 分包体积提示。

本机仍使用 `deploy/compose.ui-preview.yaml` 和 `build-a-wiki-gateway:ui-refresh`，账号和持久数据保持不变；旧 `v0.1.0-rc1` 离线包不被覆盖。

截图采集显式完成有限动画后再截取，避免将半透明退场画面误当作最终布局。`scripts/e2e.py` 可追加 Playwright 文件/筛选参数，例如 `python3 scripts/e2e.py motion.spec.ts`，用于仅复测受影响场景。截图对应的 UI 流程单独重跑通过（19.3 秒）。本轮最终前端镜像 ID 前缀为 `1a9948dd2f05`。
更新后的实际 HTTPS 入口通过部署登录与目录专项检查（2 项，3.3 秒），健康检查返回正常。测试用临时服务和隔离 schema 已自动清理，原试用服务继续运行。
